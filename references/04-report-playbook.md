# 自评报告写作：结构、数据与句式

> 报告有三个读者：监管评审人（看是否与指标对得上）、董事会与高管层（看结论与风险）、内部各部门（看自己被写成了什么样）。一篇能过关的报告要同时满足三者。

## 一、总体结构（按 2025 年通行框架）

| 部分 | 内容 | 篇幅建议 | 写作要点 |
|---|---|---|---|
| 报告对象 | 报送对象（如"××监管局"） | 1 行 | 公文格式 |
| 引言 | 依据、评价周期、自评结论 | 1 段（3–5 句） | 一句话交代依据文件与年度，一句话给结论性判断 |
| 一、自评工作组织情况 | 组织领导 / 部门协同 / 过程管控 | 3 小段 | 体现"认真"：工作组、方案、启动会、周例会、交叉复核、管理层审议 |
| 二、上年度问题整改情况 | 问题—措施—成效 | 1–2 段 | 真改了就写透（要有数据对比），改一半就简短带过 |
| 三、本年度主要亮点 | 体制机制 / 科技赋能 / 宣教服务 / 纠纷化解 | 4 小段 | 每项亮点后必须跟一句效果数据 |
| 四、自评具体情况 | 严格按当年评价表七要素展开 | 全文主体，约占 60% | 与指标逐一对应，每模块"总—分—总" |
| 五、存在的问题与改进计划 | 2–3 个真问题 + 可执行计划 | 1 段 | 问题要与低分指标呼应，计划要有时间与交付物 |
| 结语 | 表态 | 2–3 句 | 不喊口号，回扣年度判断 |

第四部分的模块划分**必须与当年《评价表》一致**，不要自创模块、不要合并要素、不要沿用去年的标题。这是最常见的退回原因。

## 二、第四部分：每个要素怎么写

统一用"总—分—总"：

> **总**：一句话判断本要素年度状态（如"体制机制持续健全，'1+N'制度体系完成年度修订并实现分支机构全覆盖"）。
> **分**：按二级指标分点，每点写"做了什么 + 怎么做的 + 结果数据"。措施用动词开头，结果用数字收尾。
> **总**：一句话说明该要素对消费者权益的实际意义（对应八大权益之一）。

各要素的数据锚点（没有数据就用可核验的事实替代，不要用形容词）：

| 要素 | 必须出现的数据类型 |
|---|---|
| 体制机制 | 制度数量与修订数、专职人员数与占比、预算金额、董事会/委员会召开次数、审查项目数与采纳率、审计次数与整改率、考核权重与覆盖部门数、培训场次/覆盖率/通过率 |
| 适当性管理 | 产品评级覆盖数、评估问卷份数、系统拦截笔数与准确率、特殊群体交易笔数、告知案例数 |
| 营销行为管理 | 审查物料份数、监测发现与整改数、双录覆盖率与质检合格率、合作机构数量与退出数、信息披露渠道数 |
| 纠纷化解 | 投诉总量与同比、15 日办结率、监管转办比率及同比、调解参与数与执行率、溯源整改条数 |
| 金融教育 | 活动场次、触达人次、网点参与率、员工参与率、原创作品数、季度风险提示期数 |
| 消费者服务 | 适老化改造项数、专区数量、特殊群体服务人次、演练次数、舆情处置件数 |
| 个人信息保护 | 检查次数与问题数、权限收敛比例、授权文本版本数、合作方检查家数 |

## 三、可复用句式（按段落位置）

**引言**
> 根据《金融机构消费者权益保护监管评价办法》（金规〔2025〕20 号）及××监管局 2025 年度消保监管评价工作方案要求，本机构对 2025 年度消费者权益保护工作进行了全面自评，现形成本报告。自评认为，本机构 2025 年度消保工作体制机制持续完善，重点领域管控有效，服务质效稳步提升，整体符合监管要求。

**自评组织**
> 成立由分管领导任组长、消保部门牵头、各业务及管理部门负责人为成员的专项自评工作组，制定并下发自评工作方案，明确任务分工与完成时限；建立周例会沟通机制，及时解决跨部门问题；对照评价表七大要素逐项自查，全面梳理制度、台账、系统截图、会议纪要、培训档案与投诉数据等底稿，报告初稿经工作组交叉复核并报管理层审议。

**上年整改（改到位时）**
> 针对上年度"××"问题，已完成××系统改造，将消保审查设为产品上线与重要营销活动审批的必经环节，实现线上留痕、不可跳过。2025 年新产品及重大营销活动消保审查执行率达 100%，审查意见采纳率 95% 以上。相关流程已固化，问题得到有效解决。

**亮点（每条都按这个结构）**
> 推出"××"机制/工具/品牌（是什么）→ 解决了什么具体问题（为什么做）→ 覆盖范围与使用量（做了多少）→ 效果数据（有什么用）。

**问题与改进**
> 在利用大数据对潜在消保风险进行前瞻性预测预警方面仍有提升空间；部分基层人员在新型复杂纠纷中的调解技巧有待加强。下一步将：①构建消保风险监测模型，对交易行为与投诉热点开展动态分析；②2026 年组织专题培训与情景模拟演练，重点提升客户经理与投诉处理人员能力；③动态优化管理体系，跟踪监管最新要求。

**结语**
> 本机构将持续把消费者权益保护置于经营发展的重要位置，坚守金融为民初心，完善消保治理体系，提升服务温度与效能，切实维护金融消费者合法权益。

## 四、好词好句库（选用，不要堆砌）

**定位与意义**：坚持长期主义的沧桑正道；赢得并留住客户信任最核心的抓手；金融工作政治性、人民性的重要体现；坚守"金融为民"理念；消费者信任是金融业发展的基石。

**格局**：构建"大消保"格局；共建共治共享的消保新格局；以系统性思维构建适应新时代要求的消保体系。

**机制建设**：将消保纳入公司治理、企业文化建设和经营发展战略，融入产品设计、信息披露、营销服务、争议解决各环节全流程；"横到边、纵到底"的责任体系；穿透式管理，确保消保要求直达业务末梢；智能化的消保风险预警与防控体系。

**服务承诺**：投诉有门、处理有速、闭环有据；首问负责制、限时办结制；从"被动应对"向"主动治理"转变，实现降量提质；坚持和发展新时代"枫桥经验"，把纠纷化解在基层、化解在萌芽。

**服务温度**：做细服务颗粒度；关注"一老一少一新"等重点群体；于无声处见尊重；将心比心，用真诚和专业赢得信任。

**宣教**：寓教于乐、精准滴灌；打通"学、懂、信、用"的链条；推动金融知识进社区、进校园、进企业、进乡村。

使用纪律：**一句漂亮话后面必须跟一个数字或一个事实**，否则删掉。形容词密度过高的报告，评审人会默认内容空洞。

## 五、禁忌清单

| 禁忌 | 后果 |
|---|---|
| 第四部分模块与当年评价表不一致 | 被认为未按表自评，整篇可信度下降 |
| 通篇"成效显著""高度重视"无数据 | 被视为材料包装 |
| 亮点与第四部分脱节（另起炉灶） | 亮点无法溯源，不计入评价印象 |
| 问题部分写"无问题" | 与监管掌握的信息冲突时，直接损害可信度 |
| 数据前后不一致（正文与报表、与评价表填报不一致） | 触及"材料不实"，可致调级调档 |
| 大段复制制度原文 | 评审人不看，稀释有效信息 |
| 把上年度整改写成"已全部完成"却无证据 | 审计/检查一查即穿 |
| 涉密内容直接写入报告正文 | 违反保密要求，材料须退回 |

## 六、报告与评价表的一致性检查（报送前必做）

1. 报告第四部分的每个模块，能否在评价表中找到对应指标行？找不到说明写偏了。
2. 报告中出现的每个数据，评价表"情况概述"栏是否一致？不一致以哪份为准，必须先内部定。
3. 报告中提到的每份制度/台账，证明材料目录里是否都有？缺一件就是"说有未证"。
4. 报告的问题部分，是否与自评扣分项对应？不对应说明自评时在藏问题。
5. 一级分支机构的数据是否已汇总进法人报告？法人得分按 50% + 50% 计算，分支机构不能缺位。

# 消保评价的能力与素质模型

> 说明：本模型把"做好消保监管评价需要什么样的人"拆成可观察、可培养、可考核的维度。其中"三性（独立性/专业性/权威性）"与各岗位能力短板来自监管文件要求与知识库实务总结（标注来源），能力分级、训练方法与选拔题库为面向评价工作的专业设计，供培训与选拔使用。

## 一、先明确岗位在做什么

消保评价岗（及牵头自评的消保部门）身上有四个角色，缺一个就会在某类指标上系统性失分：

| 角色 | 做什么 | 不做会怎样 |
|---|---|---|
| **翻译者** | 把监管条文与评价指标翻译成机构内部可执行的动作与责任分工 | 业务部门听不懂要求，材料交上来全是"我们做了" |
| **审计者** | 用证据标准反向检验内部工作，敢指出"这条我们确实没做到" | 自评虚高，正式评价落差大，整改方向失真 |
| **协调者** | 让 20 多个部门在同一张台账上按时交付，且愿意交付真实内容 | 材料靠消保部代写，机制被认定未嵌入业务 |
| **参谋** | 把评价结果翻译成管理层能决策的语言（差几分、差在哪、补什么、要什么资源） | 评价结果只变成一份存档报告，来年同样失分 |

## 二、七维能力模型

每一维给出：**定义 → 三级行为表现 → 自检问题**。三级为 L1（入门，能照做）/ L2（熟练，能独立负责一个要素）/ L3（精通，能设计机制并应对监管质询）。

### 维度 1 监管政策功（Regulatory Literacy）

- 定义：熟悉消保监管的规范体系与演变逻辑，能把具体指标回溯到条文原意。
- L1：能说清七大要素与八大权益的对应，知道 38 号文、9 号令、评价办法的基本要求。
- L2：能就任一指标指出其规范出处（办法条款、9 号令章节、部门规章或通知），并解释"监管为什么关心这件事"。
- L3：能预判监管关注点的迁移方向（如从"有没有制度"转向"机制是否真运行"），提前一年调整内部工作重心。
- 自检：能否不看资料说清"消保审查"和"消保审计"的区别与各自要证明什么？能否解释为什么 2025 年取消了偏离度考核、这意味着什么？

### 维度 2 指标解码力（Indicator Decoding）

- 定义：把"是否……"式的定性表述拆成可判分动作，识别分值落点与判定条件。
- L1：能读懂表结构，知道分值只落在二级指标上，小分加总等于上级分值。
- L2：能把一条指标拆成"有/无 + 覆盖范围 + 质量要求"三层判定，并识别"未嵌入不得分""此项不得分"这类归零条款。
- L3：能在指标未变的情况下识别当年表述的细微变化（如"营销宣传和销售环节"新增"销售"二字意味着审查范围扩大），并据此调整材料。
- 自检：拿到一条新指标，能否在 10 分钟内写出"判定条件清单 + 所需材料清单 + 责任部门"？

### 维度 3 证据与底稿能力（Evidence Craft）

- 定义：用"制度依据—执行记录—效果凭证"三段式构建可被第三方读懂的证据链。
- L1：知道六类材料及其证明效力，能按目录规范归档。
- L2：能为每条指标设计"最小充分证据包"，判断哪些材料是必要件、哪些是冗余件。
- L3：能设计常态化台账（月度归集、字段固定、口径统一），把"年底突击"变成"平时留痕"。
- 自检：给你一份截图，能否一句话说清它证明什么、还缺什么才算闭环？

### 维度 4 数据与口径能力（Data Discipline）

- 定义：掌握核心比率的口径与计算，保证内外一致、跨期可比。
- L1：会算投诉增长率、办结率、覆盖率、采纳率、应调率等基础指标。
- L2：能识别口径陷阱（自收与转办是否重复计算、分母取期末还是期间、剔除项是否经认定），并写出书面的口径说明。
- L3：能做趋势与结构分析（按业务类别、地区、渠道拆解），把数据变成整改线索，而不是汇报数字。
- 自检：本机构"全口径投诉数"的四个组成项分别是多少？剔除项的依据文件在哪？

### 维度 5 跨部门协调与推动力（Influence）

- 定义：在没有直接管辖权的情况下，让业务、科技、法务、分支机构和审计愿意配合并交付真实材料。
- L1：能发通知、能催办、能组织会议并形成纪要。
- L2：能把监管要求转成业务部门能接受的语言（风险与成本），用考核与审计结果作为推动杠杆。
- L3：能推动机制性改变（系统改造、流程嵌入、考核权重调整），并让高管层为消保站台。
- 自检：上一次需要业务部门改流程，你是靠什么推动的？如果只靠"监管要求"，说明影响力还停在 L1。

### 维度 6 表达与公文能力（Writing）

- 定义：把工作写成监管看得懂、管理层看得进、可核验的文字。
- L1：结构完整、层次清晰、无错别字、格式合规。
- L2：能做到"一句判断 + 一组数据 + 一个事实"，亮点有支撑，问题有对应整改。
- L3：能写出有洞察的报告——从数据里读出风险趋势，从问题里读出机制缺陷。
- 自检：你报告里的每个形容词，是否都能在后面找到数字或事实？删掉形容词后，报告还有信息量吗？

### 维度 7 职业操守与独立性（Integrity）

- 定义：在压力下保持客观、守住保密与真实性底线。这是"三性"中最难考核、也最容易出事的一维。
- 行为要求：
  - 不虚构、不倒签、不选择性报送；数据口径不因"好看"而调整；
  - 评价信息与材料严格控知悉范围，涉密材料不进实体、只在目录标注；
  - 审查意见不因业务压力撤回，不采纳须书面记录理由；
  - 自评敢于认账，不用"包装"替代整改；
  - 对外不将评价结果用于广告、宣传、营销（办法第十六条明确禁止）。
- 自检：如果一条指标的真实情况会让分管领导不满意，你还会照实写吗？你的答案就是这一维的真实水平。

## 三、能力短板 → 指标失分对照表（用来做诊断）

| 能力短板 | 最直接的失分表现 | 受影响指标 |
|---|---|---|
| 政策功不足 | 把"机制"讲成"制度"，材料只有文件没有痕迹 | 体制机制 8 条中 6 条 |
| 解码力不足 | 漏读"未嵌入不得分""此项不得分"，归零条款未识别 | 消保审查执行、适当性、双录 |
| 证据能力不足 | 目录与文件对不上、截图无说明、只有总部材料 | 全要素，尤其体制机制、营销 |
| 数据能力不足 | 口径与监管不一致、分母取错、跨期不可比 | 投诉数据 7 分 + 处理指标 7 分 |
| 协调力不足 | 责任部门全写消保部，业务部门材料靠代写 | 考核覆盖、培训覆盖、合作机构、适当性 |
| 表达力不足 | 报告无数据、模块与评价表不对应 | 整体印象与第四部分可信度 |
| 操守风险 | 自评虚高、整改虚构闭环、材料不实 | 可触发调级调档 |

## 四、三阶成长路径与 90 天速成

**L1 → L2（约 1 年）**：跟完一个完整评价周期（从方案到报送），独立负责 2–3 个要素，能写出口径说明与证据包。

**L2 → L3（约 2–3 年）**：负责全部要素的材料体系设计，主导一次监管沟通或现场检查配合，能向董事会汇报评价结果与整改方案。

**90 天速成计划（新接手评价工作的人）**

| 周次 | 任务 | 产出 |
|---|---|---|
| 第 1–2 周 | 通读当年评价表与办法，用 `build_ledger.py` 生成台账，逐条标注"我们现在有什么" | 指标台账初稿 |
| 第 3–4 周 | 对每个要素找 1 份"能拿满分"的材料样板，作为内部标准 | 材料样板库 |
| 第 5–6 周 | 跑一遍 `evidence_audit.py`，找出零材料与弱证据指标 | 缺口清单 |
| 第 7–8 周 | 补齐归零型指标（有无型），锁定数据口径并写说明 | 补件完成 + 口径说明 |
| 第 9–10 周 | 写报告第四部分，与台账逐条对齐 | 报告初稿 |
| 第 11–12 周 | 按 27 条失分点自查 + 模拟打分 + 管理层汇报 | 诊断报告 + 汇报材料 |

## 五、能力自评量表（1=不具备，5=可作为内部讲师）

| 能力项 | 关键行为 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 政策功 | 能就任一指标说清规范出处与监管原意 | | | | | |
| 解码力 | 能独立把指标拆成判定条件 + 材料 + 责任部门 | | | | | |
| 证据能力 | 能设计最小充分证据包并识别伪闭环 | | | | | |
| 数据能力 | 能写出被审计认可的口径说明 | | | | | |
| 协调力 | 能推动业务部门改流程而非代写材料 | | | | | |
| 表达力 | 报告每个判断都有数据或事实支撑 | | | | | |
| 操守 | 在压力下仍照实自评并留痕 | | | | | |

合计 28 分以上：可担任评价牵头人；20–27 分：可负责要素；20 分以下：需在政策功与证据能力上先补课。

## 六、团队配置建议（按机构规模）

| 机构类型 | 建议配置 | 结构要求 |
|---|---|---|
| 法人机构（中型） | 3–5 人专职 | 至少 1 人精通数据口径、1 人精通制度与审查、1 人负责材料体系与报送 |
| 法人机构（大型） | 5–8 人 + 各部门联络人 | 设"要素 owner"制，七个要素各有牵头人；设材料管理员统一目录与版本 |
| 一级分支机构 | 1–2 人专职 + 条线兼职 | 必须有人能独立完成本机构自评表填报与材料归集 |
| 小微型机构 | 1 人专职（可兼） | 优先保证"制度 + 台账"两件事不断档，善用模板与外部支持 |

配置的底层逻辑：评价要覆盖 35 条左右二级指标、上百个三级判定点、上千份材料，**靠一个人"扛"必然演变为年底突击**，而 2025 年度只收两次材料、无补正机会，突击模式已经失效。

## 七、培训课程包（可直接排课）

| 课程 | 对象 | 时长 | 核心内容 |
|---|---|---|---|
| 1. 评价办法与计分逻辑 | 全员 + 管理层 | 90 分钟 | 七要素、权重、五级九档、三种失分结构、结果运用 |
| 2. 指标解码工作坊 | 要素 owner | 半天 | 逐条拆解当年评价表，产出判定条件与材料清单 |
| 3. 证据链与目录规范 | 材料管理员、各部门联络人 | 半天 | 六类材料、三段式、命名与目录、常见瑕疵 |
| 4. 数据口径与计算 | 数据岗、投诉岗 | 半天 | 六个核心比率、口径陷阱、口径说明写法 |
| 5. 报告写作与公文规范 | 牵头人、写手 | 半天 | 结构、数据锚点、句式、禁忌、一致性检查 |
| 6. 案例复盘（失分诊断） | 全员 | 90 分钟 | 用 27 条失分点做本机构体检，形成整改台账 |

## 八、选拔与面试题库（带考察点）

1. 消保审查和消保审计分别要证明什么？如果只能各交一份材料，你交什么？（考察政策功 + 证据能力）
2. 一条指标写着"未嵌入此项不得分"，你怎么判断本机构是否真的嵌入了？（考察解码力）
3. 本机构全口径投诉数怎么算？四个组成项分别从哪个系统取？（考察数据能力）
4. 业务部门说"这个产品很急，先上线后补审查"，你怎么处理？（考察操守 + 协调力）
5. 董事会消保委和消保工作（事务）委员会的区别是什么？会议纪要各应由谁参加？（考察高频失分点）
6. 你发现某条指标本机构确实没做到，分管领导希望你写"基本落实"，你怎么做？（考察操守）
7. 设计一个能让材料"平时留痕"的台账，字段你会怎么定？（考察证据体系设计）
8. 投诉量同比下降 10%，但监管转办比率上升，你怎么解读、怎么向管理层汇报？（考察数据洞察 + 表达）
9. 只有两周就要报送，你如何排优先级？（考察解码力 + 项目管理：先补归零型，再补分档型，扣减型认账）
10. 你如何让 20 个部门在同一张台账上按时交真实材料？（考察协调力）
